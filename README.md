# IoT Anomaly Detection - Research & Documentation

This repository houses the research documentation and high-level architectural details for the MSc Project: **"Unsupervised Machine Learning for Industrial Sensor Anomaly Detection"**.

## 📄 Contents
- **Research Paper**: LaTeX source files and PDF.
- **System Architecture**: Diagrams (Mermaid/Excalidraw).
- **Datasets**: Sample datasets used for model training and validation.
- **Methodology**: Detailed explanation of the 9-stage data cleaning pipeline.

## 🏗️ System Overview
The system is divided into 4 specialized components:
1. **[ML Service](https://github.com/USERNAME/iot-anomaly-ml-service)**: Python/Flask ML Engine.
2. **[Backend API](https://github.com/USERNAME/iot-anomaly-backend)**: .NET Core orchestrator.
3. **[Frontend Dashboard](https://github.com/USERNAME/iot-anomaly-frontend)**: Angular data visualization.
4. **[Research](https://github.com/USERNAME/iot-anomaly-research)**: Documentation (this repo).

## 🎓 MSc Project Goals
- Implement robust anomaly detection in industrial IoT sensors.
- Compare performance of Isolation Forest, OC-SVM, and K-Means.
- Provide a user-friendly diagnostic dashboard for industrial engineers.
